MDATE local identity overlay contents

Backend:
- first-party identity domain ports, IdentityService, bcrypt password hashing, jose JWT signing/verification
- PostgreSQL identity repository with atomic registration, refresh-token rotation/reuse revocation, logout and password-reset operations
- auth controllers, zod schemas, rate limiting, JWT middleware, active-user and role middleware
- account repository refactored from Auth0 subject lookup to internal users.id
- account/training/speech route protection changed to local JWT auth
- local identity environment variables and PostgreSQL migration 004

Expo:
- AuthProvider/useAuth context
- in-memory access token, SecureStore native refresh token, HttpOnly browser refresh cookie
- common authenticated request headers, one retry on 401 after refresh
- Auth0 provider/plugin/config removed from runtime and dependencies
- local email/password screen and password-reset route
- account setup uses the MDATE account supplied by Express
